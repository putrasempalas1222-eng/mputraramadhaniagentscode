Features

What it does

Everything you need to ship code faster with AI assistance.

Agent Manager

Run multiple AI agents in parallel across isolated Git worktrees. Each session gets its own branch and task assignment.

Inline Autocomplete

Next-edit predictions with jump-to-edit UX. Press Tab to accept suggested changes directly in your code.

Terminal Integration

Explain, fix, or add terminal output to context right from the editor. AI understands your build errors live.

Multi-Provider

Connect to Anthropic, OpenAI, DeepSeek, Qwen, GLM, MiniMax, Kimi, and many more through a single unified proxy.

Custom Model Catalog

Admin dashboard to manage providers, models, pricing, and per-model token overhead without touching code.

Reasoning Control

Cycle reasoning effort levels with Ctrl+.. Switch between fast and deep thinking per session on the fly.

Project Memory

Persistent context across sessions. The agent learns your project structure, conventions, and decisions.

Browser Automation

Experimental Playwright-based browser panel. Let the agent interact with web pages for testing and research.

Installation

Get started in 4 steps

Install the extension and start coding with AI in minutes.

1

Download the VSIX file

Pick a version above and click Download. The file is self-contained — no internet required after download.

2

Install via command line

Open a terminal in VS Code and run:

code --install-extension mputraramadhani-agents-1.0.143.vsix
3

Reload VS Code

Press Ctrl+Shift+P, type Reload Window, and hit Enter. The Agent panel will appear in the sidebar.

4

Configure your provider

Open Settings, search for Agents Code, and set your default provider and model.

FAQ

Common questions

Quick answers to help you get started.

Is this extension free?

Yes. The extension is open-source under MIT. Some AI providers may have their own usage costs — check each provider's pricing page.

Do I need an API key?

At least one provider key is required to use chat or autocomplete features. Add it through the extension settings or the admin dashboard.

Can I use my own local models?

Yes. Any OpenAI-compatible endpoint works. Add your provider in the admin dashboard and the model appears automatically.

How do Agent Manager worktrees work?

Each agent session gets its own isolated Git worktree (a parallel checkout). Changes commit to separate branches so they never conflict.

Where is my data stored?

Sessions and history live locally in ~/.config/agents-code-ai/. Firebase is used only for admin management — not for conversation content.
